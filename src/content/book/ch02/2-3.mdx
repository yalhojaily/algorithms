### المسألة

**SubsetSum:** معطاة مجموعة $X$ من الأعداد الصحيحة الموجبة، وعدد صحيح هدف $T$. هل توجد مجموعة جزئية من $X$ مجموع عناصرها $T$؟

هذه **مسألة قرار** (decision problem): جوابها True أو False فقط. قد توجد مجموعات كثيرة تحقق الهدف: في المثال الأول $\{8, 7\}$ و$\{7, 5, 3\}$ و$\{6, 9\}$ و$\{5, 10\}$. لكن المسألة لا تسأل عنها، بل عن وجودها فقط. وهذه المسألة البسيطة الصياغة من أشهر المسائل **الصعبة**: في الفصل 12 سترى أنها NP-hard، أي أن أحدًا لا يعرف خوارزمية سريعة لها في كل الأحوال.

### حالتا الأساس

- **$T = 0$:** الجواب True فورًا. المجموعة الخالية مجموعة جزئية من أي مجموعة، ومجموع عناصرها صفر. والحاشية 6 تسأل: وماذا عساه أن يكون غير ذلك؟
- **$T \lt 0$، أو $T \ne 0$ و$X$ خالية:** الجواب False فورًا. كل العناصر موجبة، فلا مجموعة مجموعها سالب. ولا مجموعة جزئية من الخالية إلا الخالية، ومجموعها صفر.

### الحالة العامة: خذ أو اترك

اختر عنصرًا **أي عنصر** $x \in X$. توجد مجموعة جزئية مجموعها $T$ إذا وفقط إذا صحّ أحد أمرين:

- توجد مجموعة جزئية **تحوي** $x$ مجموعها $T$. أي: توجد مجموعة جزئية من $X \setminus \{x\}$ مجموعها $T - x$.
- توجد مجموعة جزئية **لا تحوي** $x$ مجموعها $T$. أي: توجد مجموعة جزئية من $X \setminus \{x\}$ مجموعها $T$.

فنختزل المسألة إلى نسختين أبسط، كل منهما بعنصر أقل:

```
SubsetSum(X, T):
  if T = 0
    return True
  else if T < 0 or X = ∅
    return False
  else
    x ← any element of X
    with ← SubsetSum(X \ {x}, T − x)      ⟨⟨Recurse!⟩⟩
    wout ← SubsetSum(X \ {x}, T)          ⟨⟨Recurse!⟩⟩
    return (with ∨ wout)
```

وهذا نمط سيتكرر في الفصل كله، وفي الفصل 3: **قرار ثنائي لكل عنصر**، وفي كل فرع استدعاء على بقية العناصر. ولاحظ الفرق عن الملكات: هناك كان القرار «أي عمود؟» بـ $n$ بدائل. هنا «نعم أم لا؟» ببديلين.

### الصحة: جملة عن الجنية

برهان الصحة «تمرين مباشر في الاستقراء»: إن كان $T = 0$ فالجواب صحيح. وإن كان $T$ سالبًا أو $X$ خالية فالجواب صحيح. وإلا، فإن وُجدت مجموعة مجموعها $T$، فهي إما تحوي $x$ وإما لا تحويه، و**جنية الاستدعاء** تفحص كلًا من الاحتمالين بشكل صحيح. انتهى.

وجنية الاستدعاء هنا اسم آخر لـ **فرض الاستقراء**: نفترض أن الاستدعاءات على المسائل الأصغر صحيحة، كما في الفصل 1. والبرهان كله فقرة لأن الحالة العامة **مبنية** على تقسيم كامل للاحتمالات (يحوي $x$ / لا يحويه). وهذه ميزة كبرى للتراجع: الصحة شبه مضمونة بالبناء، لأننا لا نتجاهل أي احتمال.

### من المجموعة إلى الفهارس

لنحلل الزمن، يجب أن نحدد بعض التفاصيل. لنفترض أن $X$ مصفوفة $X[1 .. n]$. والخوارزمية تسمح باختيار أي $x$. فأي اختيار يجعل $X \setminus \{x\}$ سهلة الوصف والحساب؟ **العنصر الأخير** $X[n]$: فالباقي هو البادئة $X[1 .. n - 1]$.

لكن نسخ البادئة في كل استدعاء يكلف $\Theta(n)$. فبدل النسخ نمرر **قيمتين**: مرجعًا إلى المصفوفة (أو عنوان بدايتها)، وطول البادئة. أو نجعل $X$ متغيرًا عامًا (global). فتصبح المسألة: «هل توجد مجموعة جزئية من $X[1 .. i]$ مجموعها $T$؟»

```
SubsetSum(X, i, T):
  if T = 0
    return True
  else if T < 0 or i = 0
    return False
  else
    with ← SubsetSum(X, i − 1, T − X[i])
    wout ← SubsetSum(X, i − 1, T)
    return (with ∨ wout)
```

وهذه الخطوة، من «مسألة على مجموعة» إلى «مسألة على فهرس»، تبدو تفصيلًا تقنيًا. لكنها ستكون **حاسمة** في الفصل 3: حين تصبح المسائل الجزئية محددة بأعداد صحيحة صغيرة $(i, T)$، يمكن حفظ أجوبتها في جدول.

### الزمن

كل استدعاء يقوم بعمل ثابت واستدعاءين على $i - 1$:

$$
T(n) \le 2\,T(n - 1) + O(1).
$$

وهذه علاقة أبراج هانوي، فحلها $T(n) = O(2^n)$، بطريقة يسميها Erickson ساخرًا «أوه نعم، حللنا هذه في أبراج هانوي». وفي أسوأ الحالات، مثلًا حين يكون $T$ أكبر من مجموع كل العناصر، الشجرة **ثنائية كاملة** عمقها $n$، والخوارزمية تفحص كل المجموعات الجزئية الـ $2^n$.

تابع الشجرة. الفرع الأيسر يأخذ $X[i]$، والأيمن يتركه:

<Callout type="tip" title="والاستدعاء الثاني إن نجح الأول؟">
الكتاب يحسب `with` و`wout` كليهما ثم يأخذ $\lor$. وفي معظم لغات البرمجة، $a \lor b$ لا يحسب $b$ إن كان $a$ صحيحًا (short-circuit). جرّب الخيار في المحاكاة: الشجرة تصغر حين يوجد حل، لكن أسوأ الحالات (لا حل) لا تتغير إطلاقًا. والتحليل في الكتاب عن أسوأ الحالات.
</Callout>

### النسخ الأخرى

بتعديلات صغيرة نحل نسخًا أخرى. Figure 2.6 تبني المجموعة نفسها، أو تعيد None إن لم توجد:

```
ConstructSubset(X, i, T):
  if T = 0
    return ∅
  if T < 0 or i = 0
    return None
  Y ← ConstructSubset(X, i − 1, T)
  if Y ≠ None
    return Y
  Y ← ConstructSubset(X, i − 1, T − X[i])
  if Y ≠ None
    return Y ∪ {X[i]}
  return None
```

(صححت $n = 0$ في الكتاب إلى $i = 0$.) الزمن ما زال $O(2^n)$، ويقول الكتاب إنه يبقى كذلك حتى لو كلف الإدراج $O(n)$. وبالطريقة نفسها نعدّ المجموعات التي مجموعها $T$ (التمرين 1(a))، أو نختار **أفضلها** بمعيار آخر (التمرين 1(b)).

**والدرس العام:** أغلب المسائل التي تُحل بالتراجع لها هذه الخاصية: الاستراتيجية الاستدعائية نفسها تحل نسخًا كثيرة. ولهذا ينصح Erickson: عند تصميم خوارزمية تراجع، **صمّم لأبسط نسخة ممكنة**: عدد، بل قيمة منطقية واحدة، لا بنية معقدة. ثم عدّل.

<Callout type="warning" title="أخطاء شائعة">
- نسيان حالة الأساس $T = 0$ (المجموعة الفارغة تكفي) أو الخلط بينها وبين $T < 0$.
- الظن أن الترتيب يقلل الزمن الأسي: التقليم يساعد عمليًا، لا في أسوأ حالة.
</Callout>

### تمارين إضافية بحلول كاملة

<Exercise id="e1" level="apply" title="مجموع بأعداد سالبة">

لو سمحنا بأعداد سالبة في $X$، أي سطر في SubsetSum يصبح خاطئًا؟ أصلحه.

<div slot="hint">هل يعني $T \lt 0$ الآن أنه لا حل؟</div>
<div slot="solution">

السطر «else if $T \lt 0$ ... return False» يصبح خاطئًا: هدف باقٍ سالب لم يعد يعني الفشل، فقد يعيده عنصر سالب لاحق إلى الصفر. وكذلك يصبح التوقف عند $T = 0$ مبكرًا نوعًا ما، لكنه **ما زال صحيحًا**: وصلنا إلى مجموعة مجموعها الهدف، فالجواب True.

الإصلاح: احذف شرط $T \lt 0$ فقط:

```
if T = 0: return True
else if i = 0: return False
else: return SubsetSum(X, i − 1, T − X[i]) ∨ SubsetSum(X, i − 1, T)
```

والزمن ما زال $O(2^n)$، لكننا فقدنا القطع الذي كان يوفره شرط $T \lt 0$. (وإن أردت ألا تُقبل المجموعة الخالية حلًا حين $T = 0$، فهذه مسألة أخرى بمواصفة أخرى.)

</div>
</Exercise>

<Exercise id="e2" level="prove" title="برهان O(2ⁿ) بالاستقراء">

ليكن $C(i)$ عدد الاستدعاءات التي يقوم بها SubsetSum$(X, i, T)$ (أي $T$). برهن أن $C(i) \le 2^{i+1} - 1$.

<div slot="hint">$C(0) = 1$، و$C(i) \le 1 + 2C(i - 1)$.</div>
<div slot="solution">

**الأساس:** $C(0) = 1 = 2^1 - 1$. وكذلك أي استدعاء ينتهي فورًا يكلف 1.

**الخطوة:** الاستدعاء إما ينتهي فورًا (1)، وإما يستدعي مرتين على $i - 1$: $C(i) \le 1 + 2(2^i - 1) = 2^{i+1} - 1$. ∎

والحد يتحقق بالضبط حين لا يحدث أي قطع، كما في المثال الأخير في المحاكاة: $T$ أكبر من مجموع العناصر.

</div>
</Exercise>

<Takeaways>

- **SubsetSum:** مع $X[i]$ (الهدف $T - X[i]$)، أو بدونه (الهدف $T$). وحالات الأساس: $T = 0$ True، و$T \lt 0$ أو $i = 0$ False.
- **الصحة:** تقسيم كامل للاحتمالات + جنية الاستدعاء (فرض الاستقراء).
- **الفهارس:** $X[1 .. i]$ بدل $X \setminus \{x\}$: بلا نسخ، ومسائل جزئية بأعداد صحيحة.
- **الزمن:** $T(n) \le 2T(n - 1) + O(1) = O(2^n)$، وشجرة كاملة في أسوأ الحالات.
- **النسخ:** البناء والعدّ والأفضل بالاستراتيجية نفسها. فصمّم لأبسط نسخة أولًا.
